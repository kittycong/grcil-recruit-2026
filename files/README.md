# 내려받기용 서식 폴더

이 폴더에 파일을 넣으면 「할 일」 탭의 **준비물** 줄에서 해당 서식 이름이
내려받기 단추로 바뀝니다. 파일이 없으면 그냥 글자로 남으므로,
넣을 수 있는 것부터 하나씩 넣으셔도 됩니다.

## 넣는 방법

1. 파일을 이 폴더에 넣습니다 (이름은 아래 표대로).
2. `manifest.json`에 번호를 적습니다 — 예: `["01", "05", "07"]`

파일 이름을 바꾸기 어려우면 이름을 직접 적어도 됩니다. 확장자는 `.hwp`든 `.hwpx`든 상관없습니다.

```json
{ "01": "01_일정 기준표.hwp", "05": "응시자 통지 기록부.hwpx" }
```

적어 넣은 것만 화면에 단추로 나옵니다. 실수로 올라간 파일이 그냥 노출되지 않게
두 단계로 나눠 두었습니다.

## 파일 이름

이름을 아래와 정확히 맞춰 주세요.

| 넣을 파일 이름 | 서식 |
|---|---|
| `서식-01.hwpx` | 일정 기준표 |
| `서식-02.hwpx` | 수령 문서 점검표 |
| `서식-05.hwpx` | 응시자 통지 기록부 |
| `서식-06.hwpx` | 실기시험 실시 기록부 |
| `서식-07.hwpx` | 채용서류 파기 점검표 |
| `서식-08.hwpx` | 적격 여부 확인 기록표 |
| `서식-09.hwpx` | 근로계약 체결 점검표 |
| `서식-10.hwpx` | 신규 입사 행정처리 점검표 |
| `서식-11.hwpx` | 시용기간 일정 산출표 |
| `서식-12.hwpx` | 인사기록 편철 목록 |

## 여기에 올리면 안 되는 것

**이 사이트는 주소를 아는 사람이면 누구나 볼 수 있습니다.** 응시자도 봅니다.
아래 문서는 절대 넣지 마십시오.

- **실기시험 과제지** — 응시자가 미리 보면 시험이 무효가 됩니다
- **모범답안 · 실기 채점표** — 같은 이유
- **면접 문항 · 진행지침**
- **서식 03 응시번호·성명 대조표** — 대외비
- **서식 04 편의 제공 접수·처리표** — 대외비, 장애 관련 정보가 들어갑니다
- 응시자의 지원서류, 답안, 평가표 등 **사람 정보가 들어간 모든 문서**

빈 서식(작성 전 양식)만 올리고, **내용이 채워진 문서는 올리지 않습니다.**
채워진 문서가 필요하면 센터 내부 공유 폴더를 쓰십시오.
