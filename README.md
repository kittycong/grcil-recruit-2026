# 사무국장 채용 일정 안내

구로장애인자립생활센터 2026년 사무국 사회복지사(사무국장) 공개채용의 **진행 일정 안내 페이지**입니다.

- 역할을 고르면 그 역할이 챙길 일정만 보입니다
- 날짜별 준비물, 달력, 문서 보관 기준, 전체 흐름을 담았습니다
- 체크 표시는 보는 사람의 브라우저에만 저장되며 다른 사람에게 보이지 않습니다

## 담지 않은 것

응시자 개인정보, 평가 문항과 채점 기준, 위원 명단, 내부 결재 문서는 담고 있지 않습니다.
실제 기준은 게시된 채용공고와 인사위원회 의결 사항입니다.
