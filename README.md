# 사무국장 채용 실무 안내

구로장애인자립생활센터 2026년 사무국 사회복지사(사무국장) 공개채용 실무 안내 페이지입니다.

## 담은 것

- **할 일** — 역할을 고르면 그 역할이 챙길 일만 날짜순으로
- **실무 작업목록** — 담당자가 직접 하는 일 + 관련 문서 내용 펼쳐보기
- **문안 모음** — 응시자·위원 통지 문안, 홈페이지 공지문 (복사 버튼)
- **달력** — 9~12월, 할 일 있는 날 표시
- **서식** — 실무서식 01~12번 목록과 각 서식에 든 항목
- **문서** — 보존기간별 편철 기준 (채용서류 / 회의철 / 실무철 / 인사기록철)
- **전체 흐름** — 계획 의결부터 기록 파기까지 13단계

## 담지 않은 것

응시자 개인정보, 실기 과제와 채점 기준, 면접 문항, 위원 명단, 내부 결재 문서.

실제 기준은 게시된 채용공고와 인사위원회 의결 사항입니다.
